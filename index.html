EGFVPN
В базе Windows Package Manager (WinGet)
🤖 Инди-проект от разработчика для людей. Без рекламы и подписок.

Ультра-легковесный фоновый VPN-комплекс для Windows 10/11 на базе ядра Mihomo (Clash Meta) и сетевого драйвера Wintun. Обеспечивает полное системное шифрование и защиту конфиденциальности. Скрипты контроля (main loops) работают невидимо в фоне, не открывая окон терминала.
Доступные загрузки:
Скачать пакет .MSI Portable .ZIP (в Загрузки)
Установка в 1 клик через Терминал / PowerShell:
winget install egfvpn Копировать
Разработчик: wowbrocheck | Открытый исходный код

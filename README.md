# 🚀 EGF VPN Pro — Портативный VPN для Windows (на базе Mihomo)

Легковесный, быстрый и полностью портативный VPN-клиент под Windows. Не требует сложной установки и не оставляет мусора в реестре системы.

## ⚠️ КРИТИЧЕСКИ ВАЖНО ПЕРЕД ЗАПУСКОМ (Инструкция по установке)

Из-за особенностей защиты Windows, программа **НЕ БУДЕТ** работать из папки `Program Files` и может вылетать, так как ядру необходимы права на чтение и запись конфигураций.

**Сделайте три простых шага:**

1. Скачайте архив `egf-vpn-x64.zip` из раздела **Releases**.
2. Распакуйте архив и **ОБЯЗАТЕЛЬНО перенесите папку `egf-vpn` в ваши «Загрузки»** (или на Рабочий стол).
3. Запустите файл **`wii113.exe`** (или `start.bat`).

После этого программа запросит права администратора (это необходимо для создания виртуальной сетевой карты `wintun.dll`), успешно увидит все файлы серверов и запустится в фоновом режиме!

---

## 🛠 Особенности сборки:
* **Формат:** Portable (работает из папки).
* **Консольные окна / Майнлупы:** При запуске скрипты контроля соединения автоматически уходят в фон, обеспечивая стабильную работу ядра Mihomo без лишних окон на экране.
* **Безопасность:** Весь трафик шифруется на уровне системы.
